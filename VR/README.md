## Қоидаи асосӣ: як манбаи ҳақиқат

Профил дар ду ҷо ҳисоб мешавад:

| Ҷо | Кӣ | Чаро |
|---|---|---|
| Сервер | `quiz.service.ts` → `calculateScores()` | Барои вебсайт |
| Айнак | `ScoreCalculator.cs` | Барои демои **офлайн** дар фестивал |

Агар ин ду аз ҳам ҷудо шаванд, як корбар дар айнак ва дар сайт ду профили
гуногун мегирад — ва тамоми эътимоди лоиҳа мешиканад.

**Барои ҳамин:**

- Саволҳо дастӣ нусхабардорӣ **намешаванд**. Манбаъ `questions.ts` аст.
- `vr-questions.json` ва `vr-golden.json` бо скрипт сохта мешаванд.
- Тест ҳисоби C#-ро бо натиҷаи **воқеии backend** муқоиса мекунад.

### Навсозии маълумот

```bash
cd Back/nest-backend
npm run export:vr
```

Ин ду файлро дар `VR/Assets/StreamingAssets/` аз нав менависад. Онҳоро дастӣ
таҳрир накунед.

> Пас аз ҳар тағйири `questions.ts` ин фармонро иҷро кунед ва тестҳоро
> давонед.

## Иҷрои тестҳо

### Дар Unity *(вақте проект сохта шуд)*

`Window → General → Test Runner → EditMode → Run All`

### Бе Unity *(ҳозир кор мекунад)*

Ҳисоб ба `UnityEngine` вобаста нест, аз ин рӯ `QuizModels.cs` ва
`ScoreCalculator.cs` бо ҳар компилятори C# санҷида мешаванд. Дар ин лоиҳа
порт бо Roslyn (Visual Studio) санҷида шуд — **ҳамаи 42 санҷиш гузашт**:

- 12 вектори муқоиса бо backend
- 12 ҳолати канории `Number()`-и JavaScript
- 18 санҷиши рафтори офлайн

`ApiClient`, `VrConfig` ва `QuizDataLoader` ба `UnityEngine` вобастаанд ва
танҳо дар Unity санҷида мешаванд.

## Ҷои нозук: рафтори `Number()`

`ScoreCalculator.ToArrayIndex` рафтори JavaScript-ро такрор мекунад, на
`int.Parse`-и C#-ро:

| Қимат | JavaScript | Натиҷа |
|---|---|---|
| `""` | `Number("") === 0` | варианти **якум** |
| `"  "` | `Number("  ") === 0` | варианти якум |
| `null` | `Number(null) === 0` | варианти якум |
| `"2.7"` | `options[2.7] === undefined` | вариант нест |
| `"abc"` | `Number("abc") === NaN` | вариант нест |
| `"99"` | берун аз ҳудуд | вариант нест |

Агар ин ҷо танҳо `int.TryParse` мебуд, сатри холӣ дар айнак «вариант нест»
мешуд, вале дар сервер варианти якумро мегирифт — ва ҳамон як ҷавоб ду
профили гуногун медод.

## Доми Android, ки пешакӣ ҳал шуд

Дар Editor `StreamingAssets` ҷузвдони оддист. Дар Quest 2 он **дохили APK**
дар архиви фишурда мемонад — роҳаш `jar:file://…` мешавад ва ҳеҷ API-и файлӣ
онро намехонад.

`QuizDataLoader` ҳарду роҳро дорад:

- `Load()` — корутина бо `UnityWebRequest`, барои **Quest**
- `LoadSync()` — файли оддӣ, танҳо барои **Editor ва тестҳо**

Дар саҳнаҳои VR ҳатман `Load()`-ро истифода баред.

## Қоидаи дуюм: саҳна ҳеҷ гоҳ намеистад

`ApiClient` хато намепартояд ва интизории беохир надорад. Ҳар даъват ҳатман
ҷавоб мегардонад — ё аз сервер, ё аз `OfflineFallback`.

```csharp
StartCoroutine(ApiClient.Instance.Explain(scores, null, result =>
{
    resultPanel.Show(result.Data);            // ҳамеша пур аст
    if (result.IsOffline) operatorPanel.MarkOffline();
}));
```

| Ҳолат | Рафтор |
|---|---|
| Сервер ҷавоб дод | Маълумоти воқеӣ |
| Пайваст **тез** рад шуд (<3с) | Як такрор, баъд офлайн |
| **Мӯҳлат гузашт** (6с) | Такрор НЕ — рост ба офлайн |
| JSON вайрон | Офлайн |
| Ҷавоби холӣ | Офлайн |

Чаро пас аз мӯҳлат такрор намешавад: агар сервер банд бошад, кӯшиши дуюм боз
6 сония мехӯрад ва меҳмон 12 сония дар саҳнаи яхкарда меистад.

### Дар офлайн чӣ нишон дода мешавад

| Нишон дода мешавад | Нишон дода **намешавад** |
|---|---|
| Профили ҳисобкардаи айнак | Номи касб |
| Номи кластер | Номи донишгоҳ |
| Матни устувори шарҳ | Пини харита |
| «Инро намедонам» | Рақами тахминӣ |

Номи касб ва донишгоҳ танҳо дар база ҳастанд. Рӯйхати холӣ аз номи сохта
беҳтар аст — тести `Offline_nomi_kasbi_sokhta_namedihad` инро нигоҳ медорад.

## Танзимот

`VrConfig` ҳамчун ScriptableObject аст, на const дар код:
`Assets → Create → Ихтисоси ман → VR Config`

| Майдон | Пешфарз | Чаро дар Inspector |
|---|---|---|
| `baseUrl` | `http://localhost:3000` | Дар фестивал IP иваз мешавад — бе build-и нав |
| `timeoutSeconds` | 6 | Танзими бароҳатии саҳна |
| `language` | `tj` | Пеш аз ҳар меҳмон интихоб мешавад |
| `verboseLogging` | true | **Пеш аз фестивал хомӯш кунед** |

> Барои Android: `Player Settings → Internet Access → Require`, вагарна
> дархостҳо дар Quest бесадо мешикананд.
