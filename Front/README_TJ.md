## 📖 Дар бораи Лоиҳа

**Касби Ман (My Career)** — ин платформаи мукаммали веб мебошад, ки барои кӯмак ба ҷавонон дар интихоби дурусти касб таҳия шудааст. Платформа усулҳои психологиро (модели машҳури RIASEC) бо технологияҳои пешрафтаи зеҳни сунъӣ (AI) муттаҳид намуда, ба ҳар як корбар маслиҳату роҳнамоии инфиродӣ (шахсӣ) пешниҳод мекунад.

### Чаро ин лоиҳа муҳим аст?
Бисёре аз хатмкунандагон ва ҷавонони Тоҷикистон касби ояндаи худро бе дарки пурраи қобилиятҳои худ ва талаботи бозори меҳнат интихоб мекунанд. Ин боиси интихоби нодуруст ва бекорӣ мегардад. Лоиҳаи "Касби Ман" ин мушкилотро тавассути таҳлили илмии шахсият ва роҳнамоии рақамии дақиқ ҳал мекунад.

## ✨ Функсияҳои Асосӣ ва Вазифаҳои Онҳо

Дар ин бахш тамоми имкониятҳои система ва вазифаи ҳар яки онҳо ба таври муфассал фаҳмонида шудаанд:

### 🧠 1. Тести Психологии RIASEC (Quiz)
* **Чист?** Тести мукаммали психологӣ, ки аз 30+ саволҳои махсус иборат аст.
* **Вазифа ва Натиҷа:** Ин функсия шавқу ҳаваси корбарро дар 6 самт месанҷад (Реалистӣ, Тадқиқотӣ, Бадеӣ, Иҷтимоӣ, Ташаббускорӣ, ва Анъанавӣ). Пас аз анҷоми тест, он маълумотро дар шакли графикии визуалӣ (Radar chart) нишон медиҳад. Вазифаи ин қисм ба кластерҳои мувофиқати касбӣ (масалан, Технология ё Тиб) равона кардани корбар мебошад.

### 🤖 2. Мушовири Сунъии Касбӣ (AI Career Advisor)
* **Чист?** Мушовири худкор, ки тавассути моделҳои зеҳни сунъӣ (LLM) кор мекунад.
* **Вазифа ва Натиҷа:** Вазифаи ин функсия гирифтани натиҷаҳои тести RIASEC-и корбар ва сохтани як **Ҳисоботи инфиродӣ** аст. Вай ба корбар мефаҳмонад, ки кадом касбҳо бештар ба психологияи ӯ мувофиқанд ва харитаи роҳ (roadmap)-и таҳсил ва фаъолиятро то расидан ба он касб мекашад.

### 💬 3. Чати Касбӣ бо Зеҳни Сунъӣ (AI Chat)
* **Чист?** Муколамаи зинда (Chat) бо ёварони сунъӣ (Llama 3.3 / Gemini 2.0).
* **Вазифа ва Натиҷа:** Агар корбар дар бораи маош, талабот дар бозори меҳнат, ё малакаҳои кадом як касби дилхоҳ савол дошта бошад, метавонад дар чат мустақиман нависад. Вазифаи он пешниҳоди ҷавобҳои мушаххас ва дақиқ дар контексти Тоҷикистон мебошад (бо интизоми 5 савол дар як рӯз).

### ⚖️ 4. Воситаи Муқоисаи Касбҳо (Career Compare)
* **Чист?** Воситае барои муқоисаи зеҳнии якчанд касб.
* **Вазифа ва Натиҷа:** Корбар метавонад аз 2 то 5 касбро (масалан барномасоз ва муҳандис) интихоб кунад. Зеҳни сунъии платформа тарафҳои мусбат ва манфӣ, талабот, даромад ва сатҳи душвории омӯзиши ҳардуро таҳлил карда, **беҳтарин интихобро** ба корбар тавсия медиҳад.

### 📊 5. Панели Шахсии Корбар (Dashboard)
* **Чист?** Саҳифаи марказӣ ва шахсии корбари аз қайд гузашта.
* **Вазифа ва Натиҷа:** Дар ин ҷо маълумотҳои асосии корбар захира карда мешаванд: Натиҷаи тестҳо, фоизи мувофиқати психологӣ, таърихи суҳбатҳо ва дастрасии зуд ба воситаҳои AI.

### 🔍 6. Ҷустуҷӯ ва Пойгоҳи Касбҳо (Career Discovery)
* **Чист?** Каталоги бузурги зиёда аз 150+ касбҳои гуногун.
* **Вазифа ва Натиҷа:** Вазифаи он имкон додан ба корбар барои ҷустуҷӯ ва филтркунии касбҳо аз рӯи кластерҳост. Ҳар як касб маълумотҳои муфид, аз қабили маош ва малакаҳоро дорад ва корбар метавонад онҳоро ба рӯйхати маҳфузшудаҳояш (Favorites) илова намояд.

### 🛡️ 7. Панели Идоракунӣ (Admin Panel)
* **Чист?** Қисмати махфии система, ки танҳо барои администраторҳо дастрас аст.
* **Вазифа ва Натиҷа:** Идоракунии пурраи платформа: илова, тағйир ё тоза кардани касбҳо ва кластерҳо, инчунин назорати омори умумии шумораи корбарон ва сатҳи фаъолияти онҳо.

### 🌐 8. Системаи Бисёрзабона (Multi-language / i18n)
* **Чист?** Тарҷумаи худкори система.
* **Вазифа ва Натиҷа:** Хизматрасониро бо се забон (Тоҷикӣ, Русӣ, Англисӣ) таъмин мекунад. Ҳамаи текстҳо ва ҳатто ҷавобҳои зеҳни сунъӣ ба таври динамикӣ ба забони интихобшуда баргардонида мешаванд.

## 🛠️ Стек-и Технологӣ (Технологияҳои Истифодашуда)

Системаи мазкур бо технологияҳои замонавитарин сохта шудааст:

### Қисми Frontend (Интерфейс)
* **React 19 & Vite:** Барои сохтан ва тез кор кардани вебсайт.
* **Tailwind CSS 4:** Барои дизайни зебо ва мутобиқ ба ҳама экранҳо (Responsive).
* **Framer Motion & React Three Fiber:** Барои аниматсияҳои зебо ва эффектҳои графикии 3D.
* **Zustand:** Идоракунии ҳолати система (State Management).
* **React Router 7:** Барои паймоиши саҳифаҳо.

### Қисми Backend (Сервер)
* **NestJS 11:** Фреймворки хеле устувор ва муосир барои сохтани сервери API.
* **PostgreSQL & TypeORM:** Пойгоҳи маълумот барои нигоҳдории амни додаҳо.
* **JWT (JSON Web Tokens):** Аутентификатсияи бехатар ва ҳимояи маълумотҳои корбар.

### Қисми AI (Зеҳни Сунъӣ)
Платформа системаи "Failover"-ро барои зеҳни сунъӣ дастгирӣ мекунад, ки боэътимодии баланд дорад:
1. **Groq (Модели Llama 3.3 70B):** Ҳамчун сервери асосӣ барои ҷавобҳои бениҳоят тез истифода мешавад.
2. **Google Gemini (Flash 2.0):** Провайдери эҳтиётӣ (Fallback). Агар сервери маҳдудиятро бардорад, система бе таваққуф худкор бо Gemini корро идома медиҳад.

## 🚀 Дастурамал барои Насб ва Ба Кор Даровардан

### Талабот
* **Node.js** (версияи 18+)
* **PostgreSQL** (версияи 14+)

### Қадами 1. Ба кор даровардани Backend (Сервер)

```bash
cd "A Back My career/nest-backend"
npm install
```

Файли `.env`-ро созед ва маълумотҳои пойгоҳи маълумотро илова кунед:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=my_career
DB_USERNAME=postgres
DB_PASSWORD=рақами_махфӣ

JWT_SECRET=калиди_махфии_шумо

GROQ_API_KEY=калиди_groq
GEMINI_API_KEY=калиди_gemini

CORS_ORIGIN=http://localhost:5173
```

Оғози сервер:
```bash
npm run start:dev
```

### Қадами 2. Ба кор даровардани Frontend (Интерфейс)

```bash
cd "A Front My career"
npm install
```

Файли `.env`-ро созед:
```env
VITE_API_URL=http://localhost:3004/api
```

Оғози лоиҳа:
```bash
npm run dev
```

Лоиҳа дар адреси `http://localhost:5173` фаъол мегардад.
