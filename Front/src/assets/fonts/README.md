# DejaVu Sans

Барои PDF лозим аст: китобхонаҳои PDF шрифти дарунсохт талаб мекунанд, ва
шрифтҳои стандартии PDF (Helvetica ва ғайра) кириллро умуман надоранд —
ҳарфҳои ғ ӣ қ ӯ ҳ ҷ ба ҷои худ мураббаъ мебароранд.

DejaVu Sans ҳамаи ҳарфҳои тоҷикиро дорад (санҷида шуд: ғ ӣ қ ӯ ҳ ҷ ва
шаклҳои калонашон, инчунин « » — №). Танҳо ₽ нест, ки истифода намешавад.
