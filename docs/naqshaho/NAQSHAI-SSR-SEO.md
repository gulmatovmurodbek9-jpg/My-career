# Нақша: SSR (пешсозӣ) барои саҳифаҳои ихтисос ва донишгоҳ

> Сана: 07.10.2026 · Сабаб: Google танҳо 9 саҳифаро индекс кардааст.

## Вазъи ҳозира
- `prerender-seo.js` барои ҳар саҳифа HTML-и **алоҳида ва содда** месозад, на компонентҳои воқеиро.
- 848 ихтисос `noindex` доранд, чунки тавсифашон аз қолаб буд.
- Sitemap ҳамагӣ 168 URL дорад.

## Ҳадаф
Google саҳифаро **айнан ҳамон тавр мебинад, ки корбар мебинад**: ҳамон компонентҳои React (`Layout`, `Info`, `UniversityDetail`) бо маълумоти воқеӣ, бе интизории JavaScript.

## Чӣ тавр
1. **`src/entry-server.jsx`** ҳамон масирҳои `App`-ро бо `StaticRouter` ва `react-dom/static` `prerender` месозад. Ин усул интизори `lazy()`-ҳо мешавад.
2. **`lib/ssrData.js`** маълумоти пешакиро нигоҳ медорад: дар сервер `globalThis.__SSR_DATA__`, дар браузер `window.__SSR_DATA__`.
   - `Info` ва `UniversityDetail` ҳолати аввалро аз он мегиранд, бинобар ин спиннер нишон дода намешавад.
   - Браузер баъд маълумотро нав мекунад.
3. **`scripts/prerender.mjs`** (Front):
   - маълумотро аз API мегирад: ихтисос, донишгоҳҳо, сенария, донишгоҳ ва ихтисосҳояш;
   - саҳифаро месозад ва ба `dist/info/<id>/index.html` ва `dist/universities/<id>/index.html` менависад;
   - meta, canonical ва JSON-LD-ро илова мекунад.
4. **Ба саҳифаи ихтисос** блоки «Як рӯзи корӣ» ва «Ҷиҳатҳои мусбат ва манфӣ» илова мешавад, бо ҳамон `DayTimeline` ва `ProsCons` аз «Як рӯз дар ихтисос». Ин мундариҷаи беназир барои ҳар 884 ихтисос аст.
5. **Индекс:**
   - `noindex` танҳо барои ихтисосҳое мемонад, ки на тавсифи пурра доранд ва на сенария;
   - sitemap ҳамаи саҳифаҳои индексшавандаро дорад.
6. **Deploy:** баъд аз `vite build` иҷро мешаванд `vite build --ssr` ва `node scripts/prerender.mjs`. `prerender-seo.js` барои саҳифаҳои рӯйхат мемонад.
