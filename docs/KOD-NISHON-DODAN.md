# Агар ҷурӣ гӯяд «кодро нишон деҳ»

Ҳадаф: ҷои ҳар функсияи асосиро дар **30 сония** нишон додан ва дар назди ҷурӣ **як тағйири зинда** кардан, то онҳо бубинанд, ки кодро ту медонӣ ва он воқеан кор мекунад.

---

## 0. Пеш аз баромад (5 дақиқа)

1. **VS Code**-ро бо папкаи `My Career` кушо. Шрифтро калон кун: `Ctrl` + `=` (2–3 бор), то дар проектор хонда шавад.
2. **Терминал** кушо (`Ctrl` + `` ` ``) ва ба папкаи backend гузар:
   ```
   cd Back/nest-backend
   ```
3. **Тестҳоро як бор пешакӣ иҷро кун.** Бори аввал ~1 дақиқа мегирад, бори дуюм тезтар мешавад:
   ```
   npx jest src/quiz/quiz.service.spec.ts
   ```
   Бояд **15 passed** нависад.
4. Дар браузер сайтро кушода нигоҳ дор: https://ikhtisosiman.qobus.tj

**Қоидаи ёфтани файл:** `Ctrl` + `P` ва номи файлро навис. **Ёфтани функсия:** `Ctrl` + `F` ва номи функсияро навис. Рақами сатрҳо метавонад каме иваз шавад, аммо номҳо иваз намешаванд.

3. `detectUniversityPair`: «донишгоҳи А хуб аст ё Б?».
4. `topicInUniversity`: «дар ДТТ ихтисосҳои барномасозӣ».
5. `careerInCities`: «дар Хуҷанд ё Душанбе?».

## 2. Се намоиши зинда (агар гӯянд «чизе иваз кун»)

Ҳар се намоиш бехатар аст: тағйир танҳо дар компютери ту мешавад ва дар охир бо `Ctrl+Z` бармегардад. Ба сайт ҳеҷ таъсир намерасонад.

### Намоиши А: «Тестҳо AI-ро назорат мекунанд» (беҳтаринаш)
1. `Ctrl+P` → `quiz.service.ts` → `Ctrl+F` → `hasInventedNumbers`.
2. Ин сатрро нишон деҳ:
   ```ts
   return (text.match(/\d+/g) || []).some((value) => Number(value) > 5 && !known.has(value));
   ```
   Бигӯ: «Рақами аз 5 калонтар, ки дар маълумоти мо нест, маънои онро дорад, ки AI онро бофтааст.»
3. **Хато ворид кун:** `> 5`-ро ба `> 10000` иваз кун ва нигоҳ дор (`Ctrl+S`).
4. Тестро иҷро кун:
   ```
   npx jest src/quiz/quiz.service.spec.ts
   ```
5. Тести **«рақами бофта (маош, бал) ошкор мешавад»** сурх мешавад (**FAIL**). Бигӯ: «Агар касе ин муҳофизатро суст кунад, тест фавран нишон медиҳад, ки AI метавонад маоши бофтаро нависад.»
6. **Баргардон:** `Ctrl+Z`, баъд `Ctrl+S`. Агар хоҳӣ, тестро боз иҷро кун: 15 passed.

### Намоиши Б: «Ҳадди 15%-и самтҳои баробар»
1. `Ctrl+P` → `quiz-stats.service.ts` → `Ctrl+F` → `isClear`.
2. `0.15`-ро ба `0.05` иваз кун ва нигоҳ дор.
3. Тестро иҷро кун. Тести **«натиҷаи равшан: самти аввал камаш 15% пеш»** FAIL мешавад.
4. Бигӯ: «Ҳадди 15% тасодуфӣ нест: дар тест санҷида мешавад. Агар онро бетаҳлил иваз кунем, тест огоҳ мекунад.»
5. `Ctrl+Z` → `Ctrl+S`.

### Намоиши В: «Формуларо иваз кун» (танҳо шарҳ, бе иҷро)
1. `career.service.ts` → `Ctrl+F` → `return sum + 4`.
2. Бигӯ: «Агар `+4`-ро `+6` кунем, калимаи ҷавобҳо дар **номи** ихтисос боз ҳам муҳимтар мешавад ва ихтисосҳое, ки номашон мувофиқ аст, болотар мебароянд. Ин вазнҳоро ман дастӣ гузоштам. Вақте маълумоти воқеии ММТ ҷамъ шавад, онҳоро аз рӯи мувофиқат бо интихоби воқеии хонандагон танзим мекунам.»
3. **Иваз накун ва иҷро накун:** барои иҷро сервер бояд аз нав сар шавад (~2 дақ). Танҳо шарҳ кофист.

## 4. Агар ҳаяҷон пайдо шавад

- **Суръатро паст кун.** «Як лаҳза, нишон медиҳам» гуфтан ва 3 сония ҷустуҷӯ кардан муқаррарист.
- **Файлро ёфта натавонӣ:** `Ctrl+Shift+F` (ҷустуҷӯ дар ҳамаи файлҳо) ва номи функсияро навис.
- **Ягон чиз кор накард:** ором гӯй: «Ин дар муҳити маҳаллӣ аст. Дар сайти зинда нишон медиҳам», ва дар сайт нишон деҳ.
- **Дар хотир дор:** ту ин лоиҳаро аз сифр сохтӣ. Ҷурӣ на хато, балки **фаҳмиши ту**-ро месанҷад.
