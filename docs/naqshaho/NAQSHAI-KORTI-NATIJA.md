# Нақша: Корти натиҷа барои Telegram/Instagram

**Ҳадаф:** хонанда баъди тест ё санҷиши касб тасвири зебои натиҷаро бо як ламс ба дӯстон, гурӯҳи синф ё ба Story мефиристад.
- Барои хонанда шавқовар аст: «ман инро гирифтам».
- Барои сайт рекламаи бепул аст: ҳар корт номи сайт ва QR-код дорад. Пайвандҳо дар Telegram Google-ро ҳам кӯмак мекунанд.

## 2. Андоза ва намуд
- **1080×1920 (Story)** барои Instagram ва Telegram Stories. Ин андоза асосӣ аст.
- **1080×1080 (мураббаъ)** барои паём ва гурӯҳ. Ихтиёрӣ аст, бо тугмаи «Шакл» интихоб мешавад.
- Ранги самт дар корт ҳамон ранги 5 кластер аст: техникӣ кабуд, иқтисод зард ва ғ.
- Забон: tj / ru / en, ҳамон забоне, ки сайт дорад.
- **Ном дар корт нест**, яъне маълумоти шахсӣ нест. Ихтиёрӣ: майдони «Номи шумо», агар хонанда худаш хоҳад.

## 3. Чӣ тавр кор мекунад (техникӣ)
- Тасвир **дар худи телефон** бо `canvas` сохта мешавад. Сервер ва интернети иловагӣ лозим нест ва он зуд аст.
- **Тугмаи «Фиристодан»:**
  - дар телефон менюи «Поделиться» (Web Share API бо файл) кушода мешавад: Telegram, Instagram, WhatsApp ва ғ.;
  - дар компютер, ё агар менюи «Поделиться» набошад, тасвир боргирӣ мешавад.
- **Тугмаи «Боргирӣ»:** PNG ба галерея.
- Дар корт **QR-код** бо пайванд ба сайт ҳаст, бо нишонаи `?ref=card`, то бидонем, ки чанд нафар аз корт омадаанд.
- Ҳарфҳои тоҷикӣ (ӣ ӯ қ ғ ҳ ҷ) бо ҳарфи худи сайт, бинобар ин дуруст намоён мешаванд.

## 4. Дар куҷо пайдо мешавад
| Ҷой | Тугма |
|---|---|
| Натиҷаи тест (`/quiz`) | «📤 Натиҷаро фиристед» (зери самти асосӣ) |
| Хулосаи санҷиши касб | «📤 Натиҷаро фиристед» (дар корти калони 😊/🤔) |
| Лавҳаи таъсир | + «Аз корт омаданд: N нафар» |
