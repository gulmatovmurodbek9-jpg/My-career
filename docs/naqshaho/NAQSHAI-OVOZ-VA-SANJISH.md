### Қадамҳо
- [x] 1. Саволҳои нав (қадами 1): 16 савол, вазъиятҳои воқеии ҳаёти хонанда; ҳар ҷавоб ба 1–2 кластер хол медиҳад (асосӣ 3, иловагӣ 1); бо тоҷикӣ, русӣ, англисӣ
- [x] 2. Қадами 2: агар ду кластери аввал наздик бошанд (фарқ < 15%), саволҳои ҳарду кластер пурсида мешаванд ва натиҷа бо онҳо ҳал мешавад
- [x] 3. Мувофиқати ихтисос: калидвожа танҳо аз аввали калима (на дар мобайн), пораҳои кӯтоҳ («ай») нест, вазни ном > тавсиф
- [x] 4. Саҳифаи натиҷа: кластери асосӣ + графики 5 кластер + 6 ихтисоси беҳтарин бо «чаро» + қадамҳои навбатӣ
- [x] 5. Саҳифаи савол: тозатар, рақами қадам, дар телефон қулай
- [x] 6. Санҷиши худкор: 200 корбари сунъӣ бо профилҳои маълум → натиҷа бояд ба профил мувофиқ бошад (≥ 90%)

## Б. Овози тоҷикӣ

**Аз корбар (01.10):** калимаҳои англисӣ (AutoCAD, SCADA, ETAP) тамоман гуфта намешаванд.


### Мушкилиҳо (аз гуфтаи корбар)
калимаҳоро нодуруст мегӯяд · калима/ҷумла мебурад · садо роботӣ · дер ҷавоб медиҳад · маъноҳо вайрон

### Қадамҳо
- [x] 1. Асбоби санҷиш: 60+ ҷумлаи душвор (рақам, сана, ММТ, AI, номҳои русӣ/англисӣ, ҷумлаҳои дароз) → овоз → ElevenLabs Scribe бармегардонад ба матн → муқоисаи калима ба калима. Ин рақами объективии «чанд калима гум/хато шуд» медиҳад
- [x] 2. Хондани матн: ихтисорҳо (ММТ, ДМТ, IT, AI), ҳарфҳои лотинӣ, %, сана, фосилаи рақамҳо, рақамҳои тартибӣ
- [x] 3. Буридани калима: сарҳади пораҳо, буридани хомӯшии охир, ҷумлаҳои дароз
- [x] 4. Садо: танзими noise_scale / noise_scale_w / суръат дар ONNX; муқоисаи A/B
- [x] 5. Тезӣ: ченкунии ҳар марҳала (STT → AI → TTS), ҷумлаи аввал пештар садо диҳад
- [x] 6. «Маъноҳо вайрон»: ҷавобҳои ёварро санҷидан (грамматика, маъно) — мисолҳо аз корбар лозим

### Натиҷа (01.10.2026, дар сайт)
Санҷиш: 30 ҷумлаи душвор × 2 бор → овоз → ElevenLabs Scribe → муқоиса (`Back/nest-backend/voice-eval.js`).

| | Пештар | Ҳозир |
|---|---|---|
| Хатои калимаҳо (WER) | 27,1% | ~20% |
| Калимаи аввал дуруст | 44/60 | 49/60 |
| Калимаи охир дуруст | 38/60 | 49/60 |
| Калимаҳои англисӣ (AutoCAD, SCADA, ETAP) | тамоман гуфта намешуданд | гуфта мешаванд (бо талаффузи тоҷикӣ) |

Чӣ иваз шуд:
- **Модел:** ҳамон модели сайт, вале тасодуф кам (noise 0.667 → 0.2, duration 0.8 → 0.3). Модели кӯҳна: сервер `/root/voice-model-backup-*`, маҳаллӣ `voice-model-kuhna-0667`.
- **Матн** (`src/voice/tj-text.ts`): лотинӣ → кириллӣ (луғат + ихтисорҳо ҳарф ба ҳарф), %, +, «1 500 – 2 800» → «… то …», ы→и, щ→ш.
- **Вергул:** модел вергулро намедонад — ҷумла дар «, ; :» бо таваққуфи 0,14 с ҷудо мешавад.
- **Тезӣ:** ҷумлаи аввали дароз бе вергул низ бурида мешавад (садо ~1 с пештар); AI 1–2 с, синтез дар сервер 1–2 с.
- **Маъно:** ёвар ба саволи маош, нарх ва ҷойи ройгон аз база ҷавоб медиҳад; «духтур» → Кори табобатӣ (пештар дандонпизишкӣ); «Донишгоҳи тиббӣ дар куҷост» → донишгоҳ (на коллеҷ) ва шаҳраш; «ту кистӣ»; самтҳо барои ҳуқуқшинос, барномасоз, омӯзгор.

Намунаҳо барои гӯш кардан: `tajik-tts/muqoisa/` (1 — пештара, 3 — ҳозира).

### Ҳанӯз боқӣ
- Садои «роботӣ» пурра нест намешавад: ин сифати худи модел аст. Ислоҳи пурра — омӯзиши дубора бо сабтҳои бештар (на камтар аз 2–3 соат сабти тоза).
- Калимаҳои англисӣ бо аксенти тоҷикӣ гуфта мешаванд — модел садоҳои англисиро намедонад.
