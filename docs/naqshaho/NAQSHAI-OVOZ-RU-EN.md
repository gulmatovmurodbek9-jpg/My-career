## Қадамҳо
1. **Санҷиш дар компютери маҳаллӣ (бе тағйири лоиҳа)**: `sherpa-onnx-node`-ро дар папкаи муваққатӣ насб, ду моделро бор, 3 ҷумла барои ҳар забон созам; RAM (RSS) ва вақти синтезро чен кунам; рақамҳоро («4000», «611», «2026») санҷам — Piper ва Kokoro рақамро худашон мехонанд (espeak-ng); агар нодуруст бошад, `spellNumbers(text, 'ru'|'en')`-и ҳозираро истифода мекунам.
2. **Иҷозатнома**: MODEL_CARD/README-и ҳарду архивро хонам ва дар README нависам (Kokoro-82M — Apache-2.0 гуфта мешавад; Piper dmitri — аз model card санҷида мешавад; espeak-ng-data — GPL-3.0, бояд қайд шавад).
3. **Код** (рӯйхати файлҳо дар поён): модули нав `sherpa-tts.ts` — моделро танҳо бори аввал, ки забонаш лозим шуд, бор мекунад (lazy); як синтез дар як вақт (навбати умумӣ бо тоҷикӣ); WAV бо sample rate-и дурусти ҳар модел; матни дароз ба ҷумлаҳо; кэши дискӣ бо hash-и `(забон + матн)`.
4. **Намунаҳо**: 3 WAV барои ҳар забон дар `tajik-tts/namuna-ru-en/` (tj ҳам барои муқоиса).
5. **Ҳисобот ба корбар**: RAM, вақт, натиҷаи рақамҳо, иҷозатномаҳо, пайванди намунаҳо. Агар Kokoro нағунҷад ё суст бошад — алтернатива (дар поён).
6. **Деплой — танҳо баъди иҷозати дуюми корбар.**

## Иловаҳои корбар (02.10)
1. **RAM:** модели MMS-и англисӣ (`voice-model-eng`) дигар ба RAM бор намешавад. RAM дар бадтарин ҳол чен карда мешавад — ҳар се модел (тоҷикӣ + Dmitri + Kokoro) якбора. Агар дар сервер **< 500 МБ** озод монад → фавран `kokoro-int8`.
2. **Кэш:** калиди кэши дискӣ = `забон + модел + матн` (на танҳо забон + матн), то аудиои кӯҳнаи MMS барои ru/en дода нашавад. Кэши кӯҳнаи ru/en тоза карда мешавад.
3. **Баргардонидан:** тағйирёбандаи `.env` → `TTS_RU_EN=sherpa|mms` (пешфарз `sherpa`); бо `mms` бе тағйири код ба ҳолати пештара бармегардад.
4. **Тартиб:** қадами 1 (санҷиш) → ҳисобот ва WAV → корбар гӯш мекунад → **иҷозат барои код** → **иҷозат барои деплой**.

## Хатарҳо ва алтернатива
- **Kokoro калон аст** (model.onnx ~310 МБ, дар RAM тахминан 0,6–1 ГБ). Агар RAM-и сервер нарасад ё синтез > 3 с бошад:
  - `kokoro-int8-multi-lang-v1_0` (int8, ~110 МБ, ҳамон овозҳо, am_echo ҳам) — пешниҳоди аввал;
  - ё Piper-и англисӣ (`en_US-ryan-medium`, ~60 МБ) — сабуктарин, вале овози дигар.
- `sherpa-onnx-node` бинарӣ дорад; дар Ubuntu x64 ва Windows x64 бояд бе компилятсия насб шавад — дар қадами 1 санҷида мешавад.
- Модели англисии MMS-и корбар (`voice-model-eng/`) дар сервер нест карда намешавад, танҳо истифода намешавад (метавон баргардонд).

## Натиҷаи қадами 1 (санҷиш дар компютер, 02.10)

### Суръат ва RAM (Windows, 20 ядро; сервер 2 ядро — тахминан 2–3 баробар сусттар)

### Ду мушкилии ҷиддӣ
1. **Ихтилофи китобхонаҳо:** `sherpa-onnx-node` ва `onnxruntime-node` (овози тоҷикӣ) ҳар кадом `onnxruntime`-и худро доранд. Агар sherpa аввал бор шавад — модели тоҷикӣ тамоман кушода намешавад («The operating system cannot run %1»). Бо тартиби баръакс кор мекунад, вале нозук аст.
2. **Дар як process Kokoro 4–7 баробар суст мешавад** (RTF 0,7 → 3).
→ **Ҳал:** ru/en дар **process-и алоҳида** (child process): ихтилоф нест, суръат пурра, RAM-и он ҷудо чен ва идора мешавад. Овози тоҷикӣ ба он дахл надорад.

### int8
Барои ин CPU **int8 сусттар** аст (RTF 2–5) ва танҳо ~180 МБ RAM сарфа мекунад → ҳамчун иваз муносиб нест. Агар RAM нарасад, алтернативаи беҳтар Piper-и англисӣ (масалан `en_US-ryan-medium`, ~60 МБ, тез) аст — вале овози дигар.

### RAM дар сервер (ҳисоб)
Ҳозир озод ~2160 МБ; бе MMS-и англисӣ ~+150 МБ. Process-и ru/en дар бадтарин ҳол ~950 МБ → **озод тахминан ~1,3 ГБ** (> 500 МБ) — fp32 мегунҷад. Рақами дақиқ танҳо бо санҷиш дар сервер.

### Рақамҳо (садо → ElevenLabs → матн)
- **ru:** «4000» → «четыре тысячи» ✓, «611» → «шестьсот одиннадцать» ✓, «2026» ✓; «до 5000» → «до **пять** тысяч» (бояд «пяти» — падеж). Калимаи аввал «Добро» ҳамчун «Рада» шунида шуд — гӯш кардан лозим.
- **en:** ҳама калима ба калима дуруст: «4,000», «2026», «611», «2,500 to 5,000», «Hello» ✓. Танҳо «somoni» → «simoni».
→ Ҳарду модел рақамҳоро худашон мехонанд; `spellNumbers` лозим нест (ба ҷуз падежи русӣ — метавон «до/от» + рақамро дастӣ ислоҳ кард).

## Ислоҳи талаффуз (санҷида шуд, ҳанӯз дар код нест)
- **Падежи русӣ:** «от/до/с/из/около/более/менее/свыше» + рақам → родительный: «от двух тысяч пятисот до пяти тысяч», «от ста до трёхсот», «более двадцати», «до двадцати одного года»; «с 2025 года» (сол) дасткорӣ намешавад. Шунида шуд дуруст.
- **«Добро пожаловать»:** сабаб — тасодуфи VITS, на зада. Аломати зада (ó) **бадтар** кард (1/3). Бо noise 0,3/0,4: **12/12** дуруст (пештар 10/12).
- **«somoni»** → навишти `somonee` → «somoni» шунида мешавад ✓ (`so-mo-nee` ҳам, вале тире таваққуф мегузорад). Dushanbe, Khujand, Kulob — бе тағйир дуруст.

Намунаҳои нав: `ru-dmitri-padezh-1..3`, `en-kokoro-somoni-kuhna`/`somonee-nav`, `en-kokoro-shahrho`, `en-piper-ryan-1..3`.
