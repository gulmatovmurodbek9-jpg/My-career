# Сенарияи видеоҳои омӯзишӣ — «Ихтисоси ман»

**Ҳадаф:** барои ҳар саҳифаи сайт видеои кӯтоҳ (45–90 сония) созем, ки фаҳмонад: ин саҳифа барои чист, чӣ тавр бо он кор кардан мумкин аст ва баъд чӣ бояд кард.
**Забонҳо:** тоҷикӣ, русӣ, англисӣ. Тасвир дар ҳар се забон як аст, вале сайт дар видео бо ҳамон забон кушода мешавад ва садо ва зерсарлавҳа ба ҳамон забон мебошанд.
**Ҳамагӣ:** 16 видео × 3 забон = **48 файл**.

---

## 1. Чӣ тавр сохта мешавад (техникӣ)

| Қисм | Чӣ тавр |
|---|---|
| **Тасвир** | Браузер (Puppeteer) сайти воқеиро бо ҳисоби намоишӣ мекушояд ва худаш клик мекунад, менависад ва scroll мекунад. Ҳамаи инҳо сабт мешаванд. Ҳар се забон бо ҳамон амалҳо сабт мешавад. |
| **Монтаж** | **Remotion** (видео аз React): сарлавҳа, доираи равшан дар ҷое, ки клик мешавад, тирча, зум ба тугма, рақами қадам (1, 2, 3). |
| **Садо** | Овози синтетикии худи лоиҳа: тоҷикӣ (`tajik-tts`), русӣ ва англисӣ (моделҳои Sherpa дар сервер). Вариант: овози шумо (ниг. қарори 1). |
| **Зерсарлавҳа** | Дар поёни видео ҳамеша ҳаст (барои синф бе садо ва барои ношунавоён) ва ҳамчун файли `.vtt` алоҳида низ. |
| **Андоза** | **16:9 (1920×1080)** барои компютер, проектор ва YouTube. **9:16 (1080×1920)** барои телефон ва Reels (ихтиёрӣ, бо версияи телефонии сайт). |
| **Дар сайт** | Дар ҳар саҳифа тугмаи хурди **«▶ Чӣ тавр кор мекунад?»** бо тиреза ва видеои ҳамон забон. Ҳамаи видеоҳо дар саҳифаи `/help` ҷамъ мешаванд. |

**Сохтори ҳар видео:**
1. **Оғоз (3 с):** логотип ва номи саҳифа.
2. **Чаро (5–8 с):** як ҷумла дар бораи он ки ин саҳифа ба хонанда чӣ медиҳад.
3. **Қадамҳо (30–60 с):** 3–5 қадам; ҳар қадам як амал ва як ҷумла.
4. **Маслиҳат (5 с):** як маслиҳати муфид.
5. **Охир (4 с):** «Қадами навбатӣ: …» ва пайванди сайт.
