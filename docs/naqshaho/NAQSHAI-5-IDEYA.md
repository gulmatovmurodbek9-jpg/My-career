# Нақша: 5 идеяи беҳтарин (08.10.2026)

Корбар ҳамаи 5-ро интихоб кард. Тартиби иҷро:

## 1. Лавҳаи таъсир (барои ҳимоя)
- **Backend:** `GET /impact` (танҳо админ). Ҳамаи рақамҳо аз ҷадвалҳои воқеӣ ҳисоб мешаванд, корбарони намоишӣ ба онҳо дохил намешаванд.
  - **Тест:** чанд нафар сар карданд ва чанд нафар тамом карданд; баҳо ба натиҷа; ҳиссаи натиҷаҳои равшан.
  - **«Худро дар касб санҷед»:** шумораи санҷишҳо ва ихтисосҳои гуногун; боварӣ пеш → баъд; ↑ ва ↓; «фаҳмиданд, ки мувофиқ нест».
  - **Корбарони воқеӣ:** ихтисосҳои захирашуда ва нақшаҳои ҳуҷҷатсупорӣ.
  - **Фаъолият:** 14 рӯзи охир.
- **Frontend:**
  - корти «Таъсир» дар саҳифаи асосии админ;
  - саҳифаи `/admin/impact` дар реҷаи «Намоиш»: рақамҳои калон барои проектор.

## 2. Ҳуҷраи омӯзгор (рамзи синф)
- **Ҷадвалҳо:**
  - `classrooms` (id, code 6 ҳарф, name, school, grade, teacherId);
  - `classroom_members` (classroomId, userId, joinedAt).
- **Ворид шудани хонанда:** `trial_attempts."userId"`. Агар хонанда ворид шуда бошад, санҷиш ба ӯ навишта мешавад.
- **Омӯзгор** (ҳар корбари воридшуда):
  - «Синф созед» → рамз ва пайванди `/class/ABC123`;
  - рӯйхати хонандагон: тест гузашт ё не, самт, чанд касбро санҷид, боварӣ пеш → баъд;
  - ҷамъбасти синф: тақсими самтҳо, чанд фоиз тамом карданд, тағйири миёнаи боварӣ.
- **Хонанда:** пайванд ё рамзро ворид мекунад ва ҳамроҳ мешавад (бо розигӣ: «натиҷаи шумо ба омӯзгор намоён мешавад»).

## 3. Ҳисоботи волидайн (PDF)
- Саҳифаи `/report`, ки барои чоп сохта шудааст: «Захира ҳамчун PDF» тавассути браузер, ки ҳарфҳои тоҷикӣ дуруст мебарояд.
- Таркиб:
  - самт ва фоизҳо;
  - 3 ихтисоси беҳтарин бо донишгоҳҳо ва нарх;
  - касбҳои санҷидашуда;
  - нақшаи ҳуҷҷатсупорӣ;
  - маслиҳат ба волидайн.

## 4. Корти натиҷа (Telegram/Instagram)
- Тасвири PNG дар браузер (canvas), андозаи 1080×1350.
  - Тест: «Самти ман: …» ва 3 ихтисос.
  - Санҷиш: «😊 Ба ман мувофиқ: …».
- Тугмаи «Фиристодан» (Web Share бо файл дар телефон) ва «Боргирӣ».

## 5. Муқоисаи касбҳои санҷидашуда
- Ҳар санҷиши тамомшуда дар браузер (`localStorage`) ва барои корбари воридшуда дар сервер нигоҳ дошта мешавад.
- Дар `/trial` ва дар хулоса ҷадвал намоён мешавад:
  - касб;
  - ҳал шуд (x/4);
  - писанд омад (x/4);
  - баҳо;
  - боварӣ пеш → баъд.
- Беҳтарин бо ⭐ ишора мешавад.
