# Нақша: Ҳуҷраи омӯзгор (рамзи синф)

**Ҳадаф:** омӯзгор (ё мушовири мактаб) синфи худро ба сайт меорад ва мебинад, ки хонандагонаш кадом самтро гирифтанд, кадом касбҳоро санҷиданд ва боварии онҳо чӣ тавр тағйир ёфт.
- Мактаб сайтро худаш паҳн мекунад: як омӯзгор ба 25–30 хонанда мефиристад.
- Журӣ на «сайт», балки **синфи воқеӣ бо рақамҳо** мебинад.

---

## 1. Нақшҳо ва роҳи корбар

### Омӯзгор
1. Ворид мешавад (ҳисоби оддӣ) → дар менюи ҳисоб: **«Ҳуҷраи омӯзгор»**.
2. **«Синф созед»** → ном (масалан «11 „А“»), мактаб, шаҳр, синф (9/10/11).
3. Рамз мегирад, масалан **`K7M2QX`**, бо 3 роҳи фиристодан:
   - пайванд `ikhtisosiman.qobus.tj/class/K7M2QX` бо тугмаи «Нусха»;
   - **QR-код** барои тахтаи синф ё проектор;
   - **матни тайёр барои Telegram**: «Салом! Тест ва санҷиши касбро дар ин пайванд гузаред: …».
4. Саҳифаи синф (рақамҳо ба таври худкор нав мешаванд):
   - **Пешрафт:** ҳамроҳ шуданд 24 · тестро гузаштанд 18 · касб санҷиданд 11.
   - **Тақсими самтҳо:** диаграммаи 5 кластер (масалан 7 нафар табиӣ-техникӣ, 5 нафар филология ва ғ.).
   - **Боварӣ:** пеш 2.9 → баъд 3.8; «4 хонанда фаҳмиданд, ки касби интихобкардаашон мувофиқ нест».
   - **Ҷадвали хонандагон:** ном · тест ✓/— · самт (%) · касбҳои санҷидашуда · беҳтарин 😊 · боварӣ пеш → баъд · охирин фаъолият.
   - **Филтр «Ҳанӯз нагузаштаанд»** → тугмаи «Ёдраскунӣ» матни тайёрро барои гурӯҳи синф нусха мекунад.
   - **Хонанда** → ҷузъиёт: фоизи 5 самт, 3 ихтисоси беҳтарин, касбҳои санҷидашуда бо баҳо ва нақшаи ҳуҷҷатсупорӣ.
   - **Содирот:** Excel/CSV ва **ҳисоботи синф барои чоп** (барои директор ё вазорат).
5. Метавонад якчанд синф дошта бошад, онҳоро бойгонӣ кунад ва хонандаро аз синф хориҷ кунад.

### Хонанда
1. Пайванд ё QR-ро мекушояд → саҳифаи **«Ба синфи „11 А“, мактаби №5, Хуҷанд ҳамроҳ шавед»**.
2. Огоҳӣ ва розигӣ: **«Омӯзгори шумо (Ном) натиҷаи тест ва санҷишҳои шуморо мебинад.»** → «Ҳамроҳ шудан».
3. Ҳамроҳ шудан (ниг. **қарори 1**) → баъд тугмаи калон **«Тестро оғоз кунед»**.
4. Дар панели шахсӣ корти **«Синфи ман: 11 А»** бо тугмаи «Аз синф баромадан».
5. Ҳар тест ва санҷише, ки баъд мегузарад, ба таври худкор дар саҳифаи омӯзгор намоён мешавад.

## 2. Қарорҳое, ки шумо бояд қабул кунед

| # | Савол | Вариантҳо | Тавсияи ман |
|---|---|---|---|
| 1 | **Хонанда чӣ тавр ҳамроҳ мешавад?** | **А)** Бо ҳисоб (почта + рамзи тасдиқ). Натиҷаҳо дар ҳама дастгоҳҳо ҳастанд. **Б)** **Бе почта**: танҳо ном ва насаб. Сайт дастгоҳро «ба ёд мегирад». Дар мактаб тез аст (почта ва рамз лозим нест), вале агар хонанда дар дастгоҳи дигар гузарад, натиҷа ба синф намеравад. **В)** Ҳарду: бе почта сар мекунад ва баъд метавонад ҳисоб созад, ва натиҷаҳо интиқол меёбанд. | **В**. Дар пилот бисёр хонандагон почта надоранд ё рамзро интизор шуда наметавонанд. |
| 2 | **Кӣ омӯзгор шуда метавонад?** | **А)** Ҳар корбари воридшуда. **Б)** Танҳо онҳое, ки админ тасдиқ кардааст. | **А** бо назорати админ (рӯйхати синфҳо дар панели админ ва тугмаи «Манъ»). |
| 3 | **Омӯзгор чиро мебинад?** | **А)** Номи ҳар хонанда ва натиҷаи ӯ. **Б)** Танҳо рақамҳои умумии синф (беном). | **А**, чунки омӯзгор бояд ба ҳар хонанда кӯмак кунад. Хонанда пеш аз ҳамроҳ шудан огоҳ мешавад ва розӣ мешавад. |
| 4 | **Натиҷаҳои пеш аз ҳамроҳ шудан** | Натиҷаи тесте, ки хонанда пештар гузаштааст, ба синф намоён шавад ё не? | **Ҳа**, вале танҳо охирин натиҷа. |

## 3. Маълумот (база)

```
classrooms
  id            uuid PK
  code          varchar(6) UNIQUE   — 6 ҳарф/рақам, бе 0/O/1/I/L (хато хонда нашавад)
  name          varchar(60)         — «11 „А“»
  school        varchar(120)
  city          varchar(60)
  grade         smallint NULL       — 9/10/11
  "teacherId"   uuid → user.id
  archived      boolean DEFAULT false
  "createdAt"   timestamptz

classroom_members
  id            uuid PK
  "classroomId" uuid → classrooms.id (ON DELETE CASCADE)
  "userId"      uuid NULL → user.id     — хонандаи бо ҳисоб
  "guestId"     uuid NULL               — хонандаи бе почта (рамзи дастгоҳ)
  "displayName" varchar(60)             — «Ҷамшед Раҳимов»
  "joinedAt"    timestamptz
  UNIQUE ("classroomId", "userId"), UNIQUE ("classroomId", "guestId")
```

Илова ба ҷадвалҳои мавҷуда:
- `trial_attempts`: сутунҳои `"userId"` ва `"guestId"`, то санҷиш ба хонанда навишта шавад.
- `quiz_attempts`: сутуни `"guestId"` (`"userId"` аллакай ҳаст).
- **Хонандаи бе почта:** ҳангоми ҳамроҳ шудан сервер `guestId` (uuid-и тасодуфӣ) ва калиди махфӣ медиҳад.
  - Онҳо дар браузер (`localStorage`) нигоҳ дошта мешаванд.
  - Ҳар тест ва санҷиш онҳоро ҳамроҳ мефиристад.
  - Калид ҳамчун hash нигоҳ дошта мешавад, то каси дигар натиҷаро ба номи хонанда навишта натавонад.

## 4. API

| Метод | Роҳ | Кӣ | Кор |
|---|---|---|---|
| POST | `/classrooms` | омӯзгор | Синф сохтан → `{ id, code }` |
| GET | `/classrooms/mine` | омӯзгор | Синфҳои ман + рақамҳои кӯтоҳ |
| GET | `/classrooms/:id` | омӯзгори ҳамин синф | Ҷамъбаст + ҷадвали хонандагон |
| GET | `/classrooms/:id/members/:memberId` | омӯзгор | Ҷузъиёти як хонанда |
| GET | `/classrooms/:id/export.csv` | омӯзгор | Excel/CSV |
| PATCH | `/classrooms/:id` | омӯзгор | Ном, бойгонӣ |
| DELETE | `/classrooms/:id/members/:memberId` | омӯзгор | Хориҷ кардан |
| GET | `/classrooms/code/:code` | ҳама | Ном, мактаб, номи омӯзгор (барои саҳифаи ҳамроҳшавӣ) |
| POST | `/classrooms/join` | ҳама | `{ code, displayName }` → бо ҳисоб: `userId`; бе ҳисоб: `guestId` + калид |
| GET | `/classrooms/joined` | хонанда | Синфҳои ман |
| DELETE | `/classrooms/joined/:id` | хонанда | Аз синф баромадан |
| GET | `/admin/classrooms` | админ | Ҳамаи синфҳо, барои назорат ва лавҳаи таъсир |

**Ҳифз:**
- Ҳамроҳ шудан бо рамз маҳдуд аст (rate limit): 10 кӯшиш дар як дақиқа аз як IP.
- Омӯзгор танҳо синфҳои худро мебинад.
- Шумораи синфҳо: то 30 синф барои як омӯзгор ва то 60 хонанда дар як синф.

## 5. Саҳифаҳо (frontend)

| Роҳ | Чӣ дорад |

## 7. Барои пилот ва ҳимоя
- **Пеш аз пилот:** як синфи воқеӣ созед, рамзро дар тахта нависед ва бигзоред, ки хонандагон аз телефон ҳамроҳ шаванд.
- **Дар ҳимоя:** саҳифаи синфро нишон диҳед, масалан «22 хонанда, 18 тест, боварӣ 2.9 → 3.8», ва ҷузъиёти як хонандаро бе ном нишон диҳед.
- **Огоҳӣ:** маълумоти хонандагонро дар экрани ҳимоя бе иҷозат нишон надиҳед. Дар реҷаи «Намоиш» номҳо бо ҳарфҳои аввал иваз карда мешаванд (Ҷ. Р.).
